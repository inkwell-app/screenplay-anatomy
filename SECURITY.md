# Security policy

Report vulnerabilities in the checker, validation tooling or dependencies to
security@inkwell.software. Include a minimal original reproduction, package
version and expected impact. Do not attach private drafts to public issues.

The checker reads local XML without network access, rejects DTD declarations
and limits input size. It is an educational inspection tool, not a sandbox for
arbitrary attachments. Keep Node and dependencies current. Report Inkwell product
vulnerabilities through the same private address, identifying the product.
